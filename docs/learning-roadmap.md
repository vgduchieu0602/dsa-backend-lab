# DSA Learning Roadmap

## Phase 0 — Problem Solving Fundamentals

Goal:

Learn how to understand a programming problem before trying to solve it.

Concepts:

1. Input
2. Output
3. Constraints
4. Edge Cases
5. Examples
6. Brute Force
7. Optimization

---

## Phase 1 — Complexity

Learn how to reason about how an algorithm behaves when input size grows.

Concepts:

1. O(1)
2. O(n)
3. O(n²)
4. O(log n)
5. O(n log n)
6. Time Complexity
7. Space Complexity
8. Best / Average / Worst Case
