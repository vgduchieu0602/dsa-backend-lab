# DSA Backend Lab

A learning repository for studying Data Structures & Algorithms from first principles using JavaScript and TypeScript.

The goal is not to memorize LeetCode solutions.

The goal is to build the ability to reason about:

- Problem
- Input
- Output
- Constraints
- Edge Cases
- Brute Force
- Data Structures
- Algorithms
- Time Complexity
- Space Complexity
- Trade-offs
- Backend Applications

---
